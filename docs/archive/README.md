# Research and evidence archive

Retain dated research, external reviews and measured results, not intermediate
requirements, design snapshots, old task lists or planning copies.

- [Research](research/): historical market checks, sourcing, cost studies and raw intake.
- [Reviews](reviews/): earlier architecture/performance review material.
- [Diagnostics](diagnostics/): dated pilot measurements, not product qualification.
  - [September/October pilot observations](diagnostics/2026-09-to-10-pilot-observations.md):
    measured/reported findings retained from removed task/decision files, without old checklists.
  - [2026-10-30 FPS diagnostic](diagnostics/2026-10-30-pi-fps-diagnostic.md).

The only active references are [current state](../README.md),
[product requirements](../requirements/requirements.md),
[system design](../design.md) and [current research](../research/README.md).
Earlier committed requirements/design versions belong in Git history, not a
parallel documentation tree.

Historical research is retained as evidence. Its prices, recommendations and
links reflect the observation date; a removed old path does not make an old
statement current. Use the corresponding Git revision when examining that context.
Historical material never authorizes purchasing, supplier contact or product claims.
